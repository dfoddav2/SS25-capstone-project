# Scraper

This is the scraper built for 2025SS Datascience Capstone Project, created to work especially for Autoscout24 listings.

## Get Started

To use the scraper first install the required libraries via the [requirements.txt](./requirements.txt) file.

```bash
pip install -r requirements.txt
```

> [!NOTE]  
> You will need to have installed a chomedriver and headless client for Selenium to work.
> Check out [this guide](https://tecadmin.net/setup-selenium-chromedriver-on-ubuntu/) for instructions.

To run the scraper simply run `main.py` and choose from one of the possible options for scraping.
